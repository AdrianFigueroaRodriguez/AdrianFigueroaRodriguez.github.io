# ARF v6 - Adaptive Regime Framework

A comprehensive NBA analytics dashboard featuring the Adaptive Regime Framework for sports prediction modeling.

## Features

- **Debrief Tab**: Historical game analysis from March 8-14, 2026
- **Monte Carlo Tab**: 7,000 trial simulations for upcoming games
- **Parlay Scout**: Advanced parlay analysis tools
- **Parlay Lab**: Experimental modeling features
- **Framework v5**: Rule-based prediction system

## Live Data

The dashboard includes real-time SportRadar NBA data integration and live game tracking.

## Technical Details

- Built with vanilla HTML, CSS, and JavaScript
- Responsive design for mobile and desktop
- Dark theme optimized for data visualization
- WCAG AAA compliant color contrast
